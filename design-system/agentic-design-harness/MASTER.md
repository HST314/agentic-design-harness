# Agentic Design Harness 设计系统

> 页面级规则位于 `pages/<page-name>.md`；未声明的规则继承本文件。

**范围：** 桌面端企业级多智能体设计工作台

**设计倾向：** 低变化度（3/10）、低动效（2/10）、高信息密度（8/10）

## 原则

1. 状态必须可扫描、可追溯，不能只靠颜色传达。
2. 主任务、逻辑子任务和运行实例保持明确层级。
3. 专业 Agent 保持工作流自治；Harness 负责统一导航、上下文和高层状态。
4. 超过 300ms 的异步操作显示反馈；错误紧邻操作点并由辅助技术宣告。
5. 所有功能均可由键盘完成，焦点顺序与视觉顺序一致。

| 边框 | `--color-border` | `#E2E8F0` |
| 焦点环 | `--color-ring` | `#2563EB` |

正文对比度不低于 4.5:1。状态同时使用文字、图标和颜色；不使用紫粉渐变、荧光色或大面积装饰性渐变。

## 字体与排版

- 字体栈：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`，不依赖在线字体才能显示。
- 正文 14–16px、行高不低于 1.5；说明文字不小于 12px。
- 页面标题 24px/700；区域标题 18px/600；卡片标题 14–16px/600。
- 任务 ID、状态码和技术标识使用等宽字体。

## 密度与布局

| Token | 值 | 用途 |
| --- | --- | --- |
| `--space-1` | `4px` | 紧凑内联间距 |
| `--space-2` | `8px` | 图标与文字、字段间距 |
| `--space-3` | `12px` | 卡片内部小间距 |
| `--space-4` | `16px` | 标准内边距 |
| `--space-6` | `24px` | 区域间距 |
| `--radius-sm` | `6px` | 标签、输入框 |
| `--radius-md` | `10px` | 卡片、弹层 |
| `--shadow-panel` | `0 1px 2px rgb(15 23 42 / 6%)` | 卡片 |
| `--shadow-overlay` | `0 12px 32px rgb(15 23 42 / 14%)` | 抽屉、弹层 |

- 保证宽度 1280px 及以上，1440px 及以上为最佳体验；本期不承诺移动端。
- 左侧主任务栏 264px，可收起到 72px；右侧抽屉 360px，默认关闭。
- 看板列宽 288–320px，只允许工作区内部横向滚动，页面不得产生双重滚动条。
- 独立图标按钮和主要操作命中区至少 44×44px；可点击行整行高度至少 44px。

## 组件规则

- 每页只设一个主操作；危险操作二次确认。
- 输入均有可见标签；Prompt 占位文案不能代替标签。
- 提交过程展示 `loading → success/error`，同一用户意图保持同一幂等键。
- 上传队列逐文件展示等待、上传中、成功、失败、重试和取消。
- 卡片只展示业务状态，原始状态码放入详情抽屉。
- 看板是只读投影，不允许拖拽改变领域状态。
- Hover 只改变边框、背景或阴影，不使用会造成布局移动的缩放/位移。
- 使用同一套轮廓 SVG 图标，禁止 emoji 充当功能图标。
- 动效限于 150–200ms 的焦点、抽屉、菜单和状态反馈，并遵循 `prefers-reduced-motion`。

## 交付检查

- [ ] Skip Link、键盘操作和可见焦点可用。
- [ ] 图标按钮均有可访问名称，状态不只依赖颜色。
- [ ] 异步操作和错误会被辅助技术宣告。
- [ ] 1280、1440、1920px 下无内容遮挡或双滚动条。
- [ ] iframe 无法加载时有明确错误和受控的新标签回退。
- [ ] 工作台 URL 均来自 Adapter 允许列表，不接受任意用户 URL。
