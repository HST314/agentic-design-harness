# ADR 0005: Immutable Agent runtime artifact identity

- Status: Accepted
- Date: 2026-08-20

## Decision

Every process launch uses an `AgentRuntimeArtifact`, not a caller-supplied code label. The
artifact names one read-only source/package root, its entrypoint, an immutable revision and
at least one dependency lock. Harness walks the full tree through no-follow file descriptors,
rejects writable, symlinked and special entries, and records a deterministic manifest.

The lifecycle identity combines the full source manifest, selected dependency-lock entries,
the resolved interpreter binary and its environment (`pyvenv.cfg` when present). The complete
identity is persisted on the launch record. Restart validates it before stopping the live
process, so edits to imported modules, resources, locks, interpreters or environments fail
closed for the same instance.

Generated bytecode is disabled for child processes. Runtime state, configuration, logs and
deliveries remain in the instance workspace and never modify the artifact tree.
