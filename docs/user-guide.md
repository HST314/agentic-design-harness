# 创建第一个任务

打开工作台，进入“新任务”，用自然语言描述要制作的内容、使用场景、目标受众、风格和交付规格。上传素材后发送消息，Master 会把需求整理成可审阅的 TaskCard。

## 审阅并启动

逐项核对目标、已知事实、待澄清项、素材引用和交付规格。需要修改时继续在同一会话补充；确认页面显示的是最新修订后，再确认计划并启动。旧修订不会被误启动。

## 完成 Image 工作流

从任务看板打开当前 Image 工作项。专业 Agent 会在需要人工决策时暂停：

1. 回答必要的澄清问题并确认任务书；
2. 审阅艺术方向和候选图，选择主图；
3. 查看质检结果，必要时提交圈画或文字修改；
4. 确认最终图片与设计说明。

页面刷新或进程重启不会要求重做已完成的付费步骤。操作状态不明确时先刷新同一任务，不要重复创建任务。

## 审批与交付

每个分支的图片和 Markdown 说明先保持私有候选。交付页支持确认入库或退回修改；只有确认入库后，图片、说明和 BundleManifest 才会作为同一批次公开。重复提交同一确认会返回原批次，不会复制资产。

如果同一工作项产生多个分支，先比较每个分支的候选，再选择要发布的版本。退回不会删除历史候选，便于审计与复盘。

## 遇到问题

保留页面显示的稳定错误码和追踪号，刷新当前任务核对最新状态。不要粘贴秘密、用户敏感素材或临时图片链接到工单。管理员可按[故障排查](troubleshooting.md)定位运行问题。
